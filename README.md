## 一、程式用途與執行方式

本程式用來整理「桌遊體驗」與「電影欣賞」兩場活動的原始報名文字。透過字串處理（去除半形空白、轉小寫、依逗號拆分）建立保留重複紀錄的 `list`，再轉換為 `set` 進行去重與集合運算（交集、聯集、差集），並搭配 `tuple` 儲存活動名稱、`dict` 查詢單價與保存統計摘要，最後使用 `f-string` 輸出完整報名與收費資訊。

### 執行方式
1. 在 [Google Colab](https://colab.research.google.com/) 開啟 `activity_signup_你的學號.ipynb`。
2. 依序執行「測試一」、「測試二」與「測試三」三個程式碼儲存格，即可查看各組名單整理、集合比較與應收金額結果。

## 三、個人問題回答

### 問題一
> 測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用要以 3 人計算？直接把字串拆成串列，再轉成各自的集合，保留與失去了什麼？

同一人在同一場活動重複報名只算 1 人 收一次費 先存成 list 保留了原始順序與重複紀錄 轉成 set 則去除了重複項目且不保證原有順序。

### 問題二
> 測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

兩場去重名單都是 3 人（交集與聯集皆為 3 人）但兩場分開計費 所以報名人次為 $3 + 3 = 6人次 總應收則是 $3 \times 120 + 3 \times 80 = 600$ 元。
